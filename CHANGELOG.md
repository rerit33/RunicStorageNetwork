# История изменений

## 1.0.1

- Исправлен конфликт строительства с ValheimRAFT, из-за которого новые детали могли не прикрепляться к кораблю. Улучшена совместимость с другими модами, изменяющими размещение построек.

## 1.0.0

- Экспериментальные удалённые хранилища теперь включены по умолчанию в новых конфигурациях. Сохранённые настройки не меняются.
- Добавлены отдельные настройки включения Кодекса запасов, экипируемого Кодекса строителя и Рунического моста. При отключении созданные предметы и постройки сохраняются, а их рецепты и функции становятся недоступны.

- Исправлен отказ чтения удалённых сундуков, когда моды добавляют предметам дополнительные данные при загрузке.
- Крафт больше не ждёт проверки посторонних или недоступных сундуков перед подтверждением материалов из выбранных хранилищ.
- Исправлен отказ удалённого крафта из-за обновления формата сохранения инвентаря или округления прочности. Ошибка чтения одного сундука больше не прерывает проверку ресурсов в остальных.
- Добавлен Рунный кодекс строителя с рецептом на чёрной кузнице. Привяжите его к ядру и экипируйте, чтобы строить из материалов этой сети в пределах 50 м от её ядра или подключённых реле. Дальность меняется настройкой связи реле.
- Каждая книга строителя запоминает свою сеть. Используйте её на другом ядре для смены привязки; переименование сети не разрывает связь.
- Экипированный Кодекс строителя висит на кожаном поясе у левого бедра персонажа.
- Добавлен Рунический мост: задайте одинаковое имя двум мостам, чтобы соединить удалённые участки одной сети. Требует экспериментальной функции удалённых хранилищ.
- Через мосты можно крафтить, строить и забирать предметы в обычных радиусах реле. Дальнюю связь проходят только предметы, разрешённые для обычных порталов; местные ресурсы и обычные пути через реле остаются доступны.
- Мосты показывают состояние связи и тускнеют при отключении. Совпадение имён связи не объединяет независимые сети.
- Рунический рисунок на баннерах моста виден с обеих сторон.

## 0.8.8

- Добавлен экспериментальный API: другие моды могут получать список ресурсов сети и списывать материалы для своих устройств. Требует включённого экспериментального доступа к удалённым хранилищам.
- При временных сбоях запросы устройств автоматически перепроверяют сеть и остатки ресурсов. Повтор запроса не списывает материалы дважды.
- Добавлены страницы GitHub Wiki по настройкам мода и подключению API; предупреждение об экспериментальной функции в README сокращено.

## 0.8.7

- Исправлена ошибка, из-за которой при включённом экспериментальном доступе к удалённым хранилищам сундуки в мультиплеере оставались или появлялись снова после разрушения, позволяя повторно получать строительные материалы.

## 0.8.6

- Исправлено масштабирование окна хранилища при изменении разрешения экрана и настройки «Масштаб интерфейса». Спасибо [hoxton314](https://github.com/hoxton314) за помощь.
- Добавлена экспериментальная настройка для доступа к подключённым хранилищам вне области загрузки игрока в одиночной игре и мультиплеере, в том числе при входе в мир вдали от ядра.
- В экспериментальном режиме количество ресурсов в удалённых сундуках обновляется при использовании сети, включая изменения, сделанные другими игроками.
- Экспериментальная настройка выключена по умолчанию и может вызывать ошибки инвентаря. Перед тестированием сделайте резервную копию мира; после изменения настройки полностью перезапустите игру или выделенный сервер.

## 0.8.1

- Добавлен «Рунный кодекс»: создаётся на кузнице первого уровня из серебра, кристаллов, глаз грейдворфа, льняной нити и обрывков кожи.
- Добавлен «Кодекс запасов» — постамент с книгой, который строится молотком из Рунного кодекса, качественной древесины, камня, железа и красного джута. Для работы разместите его в зоне снабжения ядра или подключённого реле.
- Через Кодекс запасов можно искать предметы в подключённых хранилищах, выбирать количество и забирать их в инвентарь.
- Окно хранилища показывает количество, иконки и описания предметов. Предметы разного качества отображаются отдельно и сохраняют свои свойства при получении.
- Окно переименования сети на ядре оформлено в одном стиле с хранилищем.
- Обновлены иконки ядра и реле: направленный свет и мягкие блики лучше подчёркивают форму построек. Иконка мода обновлена вместе с иконкой ядра.

## 0.6.0

- Ускорена работа меню крафта в больших сетях: обновляются изменившиеся хранилища вместо постоянного пересчёта всех сундуков.
- Просмотр рецептов больше не резервирует материалы и не удерживает хранилища для крафта. Резерв создаётся после нажатия кнопки крафта.
- При выборе рецепта обновляются его ингредиенты, включая ресурсы, добавленные в ранее пустые хранилища.
- Исправлено исчезновение ингредиентов из меню крафта при задержке ответа или временной недоступности хранилища.
- Подтверждённые материалы остаются доступными во время анимации крафта при фоновом обновлении количества ресурсов.
- Устаревшие ответы хранилищ больше не заменяют более свежие сведения о ресурсах.
- Сокращены повторные проверки рецептов с сохранением поддержки их изменения во время игры.

## 0.5.6

- Исправлен выбор неправильного рецепта при сетевом крафте, когда моды назначают нескольким рецептам одинаковое внутреннее имя.
- Сетевой крафт теперь учитывает рецепты, добавленные, включённые или изменённые во время игры.
- После изменения рецепта больше не используются резервации ресурсов, подготовленные для его прежних требований.
- Добавлены понятные сообщения в журнале, когда не удаётся сопоставить рецепт у разных игроков.
- Поднос теперь может использовать еду из подключённых хранилищ для подачи.
- Строительство берёт ресурсы из сети инструментами из других модов, а не только ванильным молотом.
- Добавлен раздел конфигурации `Building` для выбора строительных инструментов, работающих с сетью. Изменения применяются без перезапуска игры, а в совместной игре состав определяет сервер.
- Строительство при достаточном количестве материалов в инвентаре больше не зависит от доступности сети.

Спасибо [hoxton314](https://github.com/hoxton314) за поддержку дополнительных строительных инструментов в [PR #2](https://github.com/rerit33/RunicStorageNetwork/pull/2).
